# Automation Workflows for Solopreneurs

Automate anything you do more than twice a week that doesn't require creative thinking. This repository contains playbooks, templates, and tools to help solopreneurs identify, build, and maintain automation workflows.

## Contents

- **[Playbook](playbook/)** - Step-by-step guide from identifying opportunities to advanced workflows
- **[Templates](templates/)** - Ready-to-use templates for workflow design, auditing, and documentation
- **[Tools](tools/)** - ROI calculator and automation audit spreadsheet
- **[Documentary Studio](documentary-studio/)** - Next.js + Remotion studio for Fern-style YouTube long-form documentaries (script → ElevenLabs VO → archival B-roll → rendered MP4 with a documentary coach)
- **[Fitness Trainer App](fitness-trainer-app/)** - FitCoach virtual personal trainer prototype

## Quick Start

1. Run the **Automation Audit** (`templates/automation-audit.csv`) - track your tasks for a week
2. Use the **ROI Calculator** (`tools/roi-calculator.html`) to prioritize which tasks to automate
3. Follow the **Playbook** to design and build your first workflow
4. Document your workflow using the **Workflow Template** (`templates/workflow-template.md`)

## Recommended Automation Tools

| Tool | Best For | Pricing | Learning Curve |
|------|----------|---------|----------------|
| **Zapier** | Simple 2-3 step workflows | $20-50/month | Easy |
| **Make (Integromat)** | Visual multi-step workflows | $9-30/month | Medium |
| **n8n** | Complex, self-hosted workflows | Free (self-hosted) | Medium-Hard |

**Start with Zapier** (easiest to learn), then graduate to Make or n8n when you hit limits.
