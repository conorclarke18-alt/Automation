# Automation Mistakes to Avoid

## 1. Automating Before Optimizing

Don't automate a bad process. Fix the process first, then automate it. A broken process automated is just a faster broken process.

## 2. Over-Automating

Not everything needs to be automated. If a task is rare or requires judgment, do it manually. Automation has a maintenance cost.

## 3. No Error Handling

If an automation breaks and you don't know, it causes silent failures. Always set up error alerts for every workflow.

## 4. Not Testing Thoroughly

A broken automation is worse than no automation - it creates incorrect data or missed tasks. Always test with real data before going live.

## 5. Building Too Complex Too Fast

Start with simple 2-3 step workflows. Add complexity only when the simple version works perfectly. Premature complexity leads to hard-to-debug failures.

## 6. Not Documenting Workflows

Future you will forget how this works. Write it down. Use `templates/workflow-template.md` for every workflow you build.
