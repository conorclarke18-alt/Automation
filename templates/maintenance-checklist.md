# Automation Maintenance Checklist

## Weekly Check (5 minutes)

- [ ] Scan workflow logs for errors in all active tools
- [ ] Address any failures immediately
- [ ] Verify critical workflows ran as expected

## Monthly Audit (15 minutes)

- [ ] Review all active workflows
- [ ] Is each workflow still being used?
- [ ] Is each workflow still saving time?
- [ ] Disable or delete unused workflows
- [ ] Update workflows that depend on changed tools
- [ ] Check all connected app authentications are still valid
- [ ] Review error notification channel for recurring issues

## Quarterly Review (30 minutes)

- [ ] Re-run automation audit to find new opportunities
- [ ] Calculate actual ROI for each workflow
- [ ] Evaluate whether to upgrade/change automation tools
- [ ] Update workflow documentation for any changes made
- [ ] Archive documentation for deprecated workflows
